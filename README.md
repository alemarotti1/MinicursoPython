# MinicursoPython
Material para o minicurso de python ministrado para os membros da CidadeInteligente. 

Este material está disponível para todas as pessoas, porém ele assume que você já tem conhecimento de alguma outra linguagem de programação e conhecimento de lógica de programação. Caso você não possua nenhum dos dois, possuirá dificuldade de acompanhar o material do curso.


Instalação:
1. Ir no site https://www.python.org/downloads/
2. Baixar e instalar
3. Abrir o terminal
4. Criar um ambiente virtual com "python/python3 -m venv (nome do ambiente)"
5. ativar o ambiente com "source (pasta do ambiente)/bin/activate"
6. Verificar que o nome do ambiente está do lado do diretório do terminal
